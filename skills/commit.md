# Git Commit Skill

Git 커밋을 생성하는 스킬입니다.

## Commit Format

```
<type>: <description>
```

### Types
- `feat`: 새로운 기능 추가
- `fix`: 버그 수정

## Instructions

1. `git status`로 변경된 파일 확인
2. `git diff`로 변경 내용 분석
3. 변경 내용에 맞는 type 선택 (feat 또는 fix)
4. 간결한 커밋 메시지 작성
5. 사용자 확인 후 `git add`와 `git commit` 실행

## Guidelines

- 메시지는 한글 또는 영어
- 첫 글자 소문자, 마침표 없음
- 50자 이내로 간결하게
