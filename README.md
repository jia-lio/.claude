# .claude

Claude Code 스킬 저장소

## 구조

```
.claude/
├── skills/          # 스킬 저장 폴더
└── README.md
```

## 스킬 사용법

스킬은 `skills/` 폴더에 저장됩니다. 각 스킬은 다음 구조를 따릅니다:

```
skill-name/
├── SKILL.md         # 스킬 정의 (필수)
├── scripts/         # 실행 가능한 스크립트
├── references/      # 참조 문서
└── assets/          # 템플릿, 이미지 등
```
